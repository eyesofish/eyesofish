# 功能规格 · 整屏动态方块世界

**分支** `002-fullscreen-block-world` · **日期** 2026-11-19

**目标**　访客从 GitHub 个人资料页打开独立的个人网站，看到铺满浏览器窗口的原创方块世界。向下浏览时，场景随个人介绍、项目和联系方式变化。

## 用户场景与验收

1. **P1 · 地表初访。** 打开网站即可看到姓名、个人方向和动态地貌。方云漂移，木屋位于远山与阶梯草地之间。移动端竖屏和桌面横屏都应占满背景。
2. **P1 · 探索项目。** 通过滚动或导航进入矿道，访客能看见持续的环境动效并打开具体项目。走到地下湖畔可以用邮件或 LinkedIn 联系 Yang。
3. **P2 · 自定节奏。** 访客可以用键盘暂停或继续环境动画。首次访问尊重系统的减少动态偏好，手动选择在刷新后延续。关闭脚本仍能浏览所有项目与联系方式。

## 功能要求

- 全宽、全高的场景贯穿所有内容区。地表、矿道、地下湖各有可辨识的构图与动效。
- 介绍沿用本人已公开的信息。项目与联系方式为独立可操作的文本链接。
- GitHub 的现有 Profile README 提供直达该网站的入口。个人网站拥有独立的公开地址。
- 在手机、桌面、键盘及减少动态模式下，正文与导航都可访问。场景属于装饰内容。

## 成功标准

- 在 375 × 812 与 1440 × 900 视口，到达三个章节均能看到铺满视口的场景，页面无横向滚动。
- 在相同滚动位置取样，各章节的画面在播放时变化，暂停后保持静止。打开项目、邮件和 LinkedIn 均有正确目的地。
- 公开 Pages 地址和主页入口均能以访客身份访问。

## 默认选择

沿用现有主页的英文正文和中英文姓名。以场景滚动和内容导航作为交互，沿用仓库现有作品和已公开联系方式。
