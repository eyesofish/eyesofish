# Feature Specification · GitHub 主页方块世界动效

**Feature Branch**　当前工作分支 `chore/spec-kit-setup`

**Created**　2026-11-19

**Status**　草案

**Input**　“我想要让我的 GitHub 主页看起来有那种动态效果，要《我的世界》的那种动态效果。”

## User Scenarios & Testing

### User Story 1 — 打开主页，看见会入夜的方块世界（P1）

访客在「Hi, I'm Yang / 俞洋」标题下看到一片阶梯状的草方块和一间小木屋。白天，方形云朵从屋顶上方慢慢飘过。天色转暗时，窗户亮起暖光，到清晨再熄灭。

**优先理由**　草方块的侧面露出泥土，小屋、云朵和地形都有方正的轮廓。这些细节让人一眼联想到《我的世界》，昼夜变化则让访客有理由多看一会儿。

**独立验收**　在允许自动播放的 GitHub 个人主页上，从横幅载入完成起观察两个循环。

1. 打开主页后，无需点击或悬停，3 秒内能看出云相对屋顶的位置发生了变化。
2. 从白天开始，访客能依次看到天色渐暗、窗户亮起、天亮后灯光熄灭。第二轮开始时，小屋和地形仍在原位，画面衔接处没有整幅闪白或黑屏。

### User Story 2 — 看完场景，继续读项目（P2）

想了解 Yang 的访客可以略过风景，直接阅读个人介绍、查看作品和找到联系方式。

**优先理由**　访客来主页还要读项目，装饰应给正文留出清楚的阅读顺序。

**独立验收**　在手机和桌面宽度各打开一次主页，分别使用浅色和深色主题。

1. 在四种组合中，横幅都位于标题和第一段介绍之间。能看到完整的小屋和草地，阅读正文只需上下滚动。
2. 从「A few projects」打开 `software_reco`，目的地是对应仓库。滑到文末，仍可找到原有的邮箱与 LinkedIn 入口。

### User Story 3 — 静止时也能看懂场景（P2）

关闭动画自动播放的访客可以安静地看一幅完整风景。通过屏幕阅读器浏览的人可以听到场景描述，再继续读第一段介绍。

**优先理由**　理解这幅画和浏览主页都应由访客按自己的节奏完成。

**独立验收**　分别在 GitHub 关闭动画自动播放、屏幕阅读器开启，以及图片加载失败的情况下打开主页。

1. 已关闭自动播放时，观察 5 秒，呈现的始终是同一幅完整的草地和木屋风景。
2. 使用屏幕阅读器按阅读顺序浏览时，标题之后听到一句与英文正文一致的场景描述，再听到原有个人介绍。

### Edge Cases

- 在窄屏上，云可以移出画面边界，但房屋和窗户在整个循环里都应可见。
- 横幅加载失败时，访客仍可读到标题、第一段介绍并使用原有项目链接。替代文本说明这幅图原本展示的场景。
- 访客在夜景中途看到横幅时，暖色窗光和草地轮廓依然可以辨认。

## Requirements

### Functional Requirements

- **FR-001**　个人主页标题下须有一幅方块风景横幅。草绿顶面、泥土侧面、阶梯地形和方块小屋在静止时也能辨认。
- **FR-002**　允许自动播放时，云须在画面中移动，小屋须经历白昼、入夜亮灯和清晨熄灯，随后连续循环。观看全程无需操作。
- **FR-003**　横幅须适应窄屏和宽屏，并在浅色、深色主题下完整展示小屋。文字介绍、项目和联系方式仍按原有顺序独立呈现，链接通向原目的地。
- **FR-004**　关闭动画自动播放时，横幅须呈现有意义的静止画面。图片须有一句英文替代文本，描述方块地形、木屋及画面中的变化。
- **FR-005**　横幅未能显示时，仍须能阅读个人介绍，并能从正文进入项目仓库。

## Success Criteria

### Measurable Outcomes

- **SC-001**　允许自动播放时，从横幅载入完成算起，前 3 秒能观察到云的位置变化。20 秒内能看完从白天到夜晚再回到白天的完整一轮。
- **SC-002**　连续观察两轮，窗户在每次入夜时亮起、在白天熄灭，两轮之间出现整幅空白画面的次数为零。
- **SC-003**　在 375 和 1280 像素宽度各用浅色、深色主题查看，四次均能看到完整小屋、读到简介、找到项目与联系入口，横幅造成的横向滚动为零。逐项比对改动前后的正文链接，目标地址全部一致。
- **SC-004**　关闭自动播放后观察 5 秒可辨认静止场景。使用屏幕阅读器可听到场景描述。图片加载失败时仍能进入 `software_reco`。三种访问方式分别验收。

## Assumptions

- 首版采用单幅原创风景横幅。木屋、移动的云和昼夜循环是本规格选择的美术方向。项目介绍、求职信息及 GitHub 平台自带的贡献图沿用当前主页。
- 验收以 GitHub 网站的个人主页 README 为准。是否自动播放取决于访客的偏好。[GitHub 动效设置说明](https://docs.github.com/en/account-and-profile/how-tos/account-settings/managing-accessibility-settings#managing-motion)
