# 方块横幅的场景与时间

这幅横幅的输入是场景构图和循环时间。渲染脚本从相同输入绘制相同的可见帧。主页只读取导出的成品。

| 对象 | 属性 | 渲染约定 |
| --- | --- | --- |
| 场景 | 320 × 80 逻辑像素，固定视角 | 天空、方云、木屋和阶梯草地由远及近叠放。绿色草顶与泥土侧面均可见，木屋和窗户完整落在画幅内。 |
| 地形与木屋 | 固定位置、方块纹理、屋顶和窗格 | 各帧只改变光照与窗色。夜景中屋身与背景、草顶与泥土仍可区分。 |
| 云层 | 形状、基准横坐标、重复间距 64 逻辑像素 | 每帧向右移 1 个逻辑像素，在画面两侧绘制相邻的重复图案。第 63 帧到第 0 帧在视觉上仍是向右走一步。 |
| 光照 | 日光强度、天空颜色、窗灯状态 | 天空与地面色阶在晨昏渐变，夜间窗内保留暖色。纹理位置固定，使用同一套有限色板。 |
| 循环 | 64 个采样时刻，每帧 250 毫秒 | 采样 0 至 15.75 秒，下一个时刻回到 0 秒。导出为 960 × 240，首帧是一幅可独立展示的日景。 |

## 一轮中会看到什么

| 时间 | 场景 | 窗户 |
| --- | --- | --- |
| 0 至 4 秒 | 白天，云越过屋顶 | 熄灯 |
| 4 至 8 秒 | 天色渐暗，进入黄昏 | 第 7 秒亮灯 |
| 8 至 12 秒 | 夜色稳定，地形依旧可辨 | 暖光持续 |
| 12 至 16 秒 | 天空逐渐恢复到起始日色 | 第 15 秒熄灯 |

验收时连续观察两轮。云应按同一方向经过屋顶，最后一帧到第一帧之间没有反向跳动、空帧或全屏闪烁。
